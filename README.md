
This repository contains data related to the Bachelor's thesis "Performance Engineering for Hierarchical Grids in AutoPas" by Alexander Glas.

    Said data includes template input files, python scripts that turn these templates into the input files used in training, and SLURM job arrays. These are mostly adaptions from https://github.com/SamNewcome/Algorithm-Selection-in-Short-Range-Molecular-Dynamics-Simulations/tree/main.

    Additionally this reposiory contains all jupyter notebooks used to create plots and pictures for the thesis.

    Software version:
    AutoPas and md-flexible commit id: 5bb7317
    Compiler version: GCC 13.2.0
